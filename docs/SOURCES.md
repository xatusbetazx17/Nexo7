# Official technical references

- [Qwen3.5 model catalog in Ollama](https://ollama.com/library/qwen3.5): supported model family and available sizes. Registry tags and availability can change; Nexo verifies downloaded size before admitting a model.
- [Ollama Docker documentation](https://docs.ollama.com/docker): supported container execution and GPU options.
- [Docker resource constraints](https://docs.docker.com/engine/containers/resource_constraints/): memory and swap controls.
- [Docker Desktop for Windows](https://docs.docker.com/desktop/setup/install/windows-install/): current OS, WSL and hardware requirements, installation and terms.
- [PyInstaller operating mode](https://pyinstaller.org/en/stable/operating-mode.html): bundled Python applications and platform-specific builds.
- [PyInstaller subprocess considerations](https://pyinstaller.org/en/stable/common-issues-and-pitfalls.html): shared-library search paths when invoking external tools.
- [GitHub workflow artifacts](https://docs.github.com/en/actions/tutorials/store-and-share-data): sharing native build artifacts across jobs.
- [NCBI E-utilities](https://www.ncbi.nlm.nih.gov/books/NBK25501/): PubMed search and record retrieval.

These references describe underlying components. They are not evidence that this application surpasses another model or has clinical efficacy.

- [Official Python Windows downloads](https://www.python.org/downloads/windows/) and [embeddable package documentation](https://docs.python.org/3/using/windows.html#the-embeddable-package): runtime used by the cross-assembled Windows preview.
